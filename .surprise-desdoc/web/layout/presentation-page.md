# Интерактивные элементы
---
>  
>  По центру вьюпорта расположен текущий слайд с разными интерактивными элементами и/или анимациями. Ими можно поиграться после того как Вирко закончит презентовать слайд, перед тем как переключиться на следующий, либо после завершения презентации.
>  

# Навигация по презентации
---
>  
>  По бокам текущего слайда расположены стрелки для их переключения. Внизу страницы расположены пронумерованные круги, переключающие слайды, которые активируются по ходу презентации.
>  

# Персонажи
---
>  
>  Вирко стоит ближе обычного, Инфи стоит дальше обычного. Вирко будет презентовать каждый слайд, почти весь текст будет озвучен им. Он будет высказывать своё личное мнение в конце слайда.
>
