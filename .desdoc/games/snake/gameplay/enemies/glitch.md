# Атаки
---
>  
>  Атаки босса заскриптованы и синхронизированы с музыкой.
>  

  * ###  Удар
	  * Бьёт огромным кулаком в случайную область поля
    
* ###  Шипы
	*  Случайные: Из пола с предупреждением выходят шипы в случайных местах
	*  Направленные: Шипы следуют за шерон
	*  Потоки: Летят змейкой в одном направлении до конца поля
	
* ###  Специальные
	*  Импульсы: Из середины поля разносятся импульсы
	*  Перестановка: Случайно меняет положение стен
	*  Мафия: ставит на поле случайного врага со спрайтом, пропущенным через разные кодеки для битых пикселей
