### 1. Пройти опрос

> Нужно ответить на вопросы, ответы на которые знаем только мы с ним:

| Вопрос | Ответ |
| ------ | ----- |
|        |       |
### 2. Решить головоломку

> Нужно будет правильно собрать руны инфилакси чтобы собрать слово download, нажав на образующуюся кнопку можно переместиться дальше

### 3. Подача

> Планируется добавить кнопку включения [[music]] в самый конец продолжительного пролистывания вниз и обратно вверх (без скролбара), которая после двойного нажатия ещё добавит на индексную страницу кнопку её кнопку включения-выключения (на этот раз с одного раза чтобы нажималась)

> Поведение музыки будет описано в [[background]]
